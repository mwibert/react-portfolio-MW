📌 Description

This is a single-page application (SPA) portfolio built using React and deployed on Render/Netlify. It showcases a developer’s projects, resume, and contact details. The portfolio includes:
	•	An About Me section with a photo and bio.
	•	A Portfolio section displaying six projects with links.
	•	A Contact form with real-time validation.
	•	A Header with Navigation and a Footer with Social Links.

🔗 Live Demo: View Deployed Site https://react-portfolio-mw.onrender.com
